EELS-ZEST v2.0

Theory and Methods

Mathematical definitions for fitted-ZLP sparse reconstruction, attention-selected Bose-Einstein thermometry, uncertainty, spatial diagnostics, and sparse phonon-mode source-intensity analysis.

1. Overview

EELS-ZEST separates the general problem of reconstructing an EELS spectrum from the more restrictive problem of inferring temperature. Stage 1 explains spectral shape. Stage 2 constrains temperature only with paired gain/loss evidence selected by attention.

Fitted ZLP kernel

The complete fitted ZLP is centered at 0 meV and used as the signal kernel.

Hard BE pairs

Paired attention modes constrain temperature through detailed balance.

Independent soft intensities

Other modes remain in the fit without controlling temperature.

3. Measurement Model

The measured low-loss spectrum is modeled as a fitted ZLP plus a sparse vibrational response and residual noise:

\[ y(E) = I_{\mathrm{ZLP}}(E) + I_{\mathrm{vib}}(E) + \epsilon(E). \]

The fitted spectrum is

\[ I_{\mathrm{fit}}(E) = I_{\mathrm{ZLP}}(E;\theta_{\mathrm{ZLP}}) + I_{\mathrm{vib}}(E;\theta_{\mathrm{src}},T). \]
The reconstruction uses the fitted total ZLP as the signal kernel. The aligned energy axis is therefore a first-class input condition, not a free temperature-compensation variable.

4. ZLP Model

The ZLP is represented by a bounded sum of asymmetric components:

\[ I_{\mathrm{ZLP}}(E) = \sum_{j=1}^{N_Z} A_j\, \phi_j(E-\delta-c_j;\theta_j), \qquad A_j \ge 0. \]

An asymmetric Pearson-type component can be written as

\[ \phi_{\mathrm{Pearson}}(x) = \begin{cases} \left(1+\dfrac{x^2}{m_Ls_L^2}\right)^{-m_L}, & x<0,\\[7pt] \left(1+\dfrac{x^2}{m_Rs_R^2}\right)^{-m_R}, & x\ge0. \end{cases} \]

After fitting, the signal kernel is normalized from the complete fitted ZLP:

\[ K_{\mathrm{ZLP}}(E) = \frac{\max[I_{\mathrm{ZLP}}(E),0]} {\sum_E \max[I_{\mathrm{ZLP}}(E),0]}. \]
Kernel center For prealigned input, the fitted-ZLP kernel center is fixed at \(0\ \mathrm{meV}\). A displaced kernel indicates an energy-axis or preprocessing problem that should be corrected before interpreting sparse mode positions or temperature.

5. Sparse Convolution

For positive sparse-mode centers \(E_{M,i}\), the vibrational signal is reconstructed from loss- and gain-side shifted copies of the fitted ZLP kernel:

\[ I_{\mathrm{vib}}(E) = \sum_i p_i^+ K_{\mathrm{ZLP}}(E-E_{M,i}) + \sum_i p_i^- K_{\mathrm{ZLP}}(E+E_{M,i}), \qquad p_i^+,p_i^- \ge 0. \]

The coefficients describe source-space intensity before convolution with the instrumental ZLP response. Sparsity and smoothness are regularized along the sparse mode-energy axis, while spectral fidelity is evaluated after reconvolution.

6. Stage 1 Objective

Stage 1 prioritizes spectral shape and stable ZLP separation. A representative objective is

\[ \mathcal L_1 = \left\| W(E)\left[\tilde y(E)-\tilde I_{\mathrm{fit}}(E)\right] \right\|_2^2 + \lambda_1\|\mathbf p\|_1 + \lambda_2\|\mathbf p\|_2^2 + \lambda_{\mathrm{sm}}\|D\mathbf p\|_2^2 + \mathcal R_{\mathrm{ZLP}}. \]

\(W(E)\) balances the ZLP core, vibrational windows, and tails. \(\mathcal R_{\mathrm{ZLP}}\) keeps component widths, centers, and amplitudes physically bounded. Any BE relation at this stage acts as a weak consistency cue rather than a hard temperature constraint.

7. Attention And Mode Partition

The attention profile combines signal strength, structured residuals, and source-intensity-supported features. For a mode center, paired evidence is

\[ s_i^{\mathrm{pair}} = \sqrt{ a(+E_{M,i})\,a(-E_{M,i}) }. \]

The default hard set is

\[ \mathcal H = \left\{ i:\ s_i^{\mathrm{pair}}\ge0.35 \right\}. \]

If too few hard pairs are available, the highest-scoring candidates with \(s_i^{\mathrm{pair}}\ge0.10\) may supplement the set. If the minimum pair count is still not reached, the result is flagged as insufficient hard-BE evidence.

\[ \mathcal S = \{i\}\setminus\mathcal H. \]
The solver does not turn all EM centers into hard-BE pairs when attention evidence is insufficient. This preserves a meaningful distinction between temperature evidence and shape-only reconstruction.

8. Stage 2 Thermometry

Hard-BE contribution

For \(i\in\mathcal H\), anti-Stokes source intensity is generated from the Stokes source intensity by Bose-Einstein detailed balance:

\[ p_i^-(T) = p_i^+(T) \exp\left[ -\frac{E_{M,i}}{k_BT} \right]. \]

Soft source-intensity contribution

For \(i\in\mathcal S\), loss and gain source intensities remain independent:

\[ p_{i,\mathrm{soft}}^+\ge0, \qquad p_{i,\mathrm{soft}}^-\ge0. \]

The complete reconstructed signal is

\[ I_{\mathrm{vib}}(E,T) = I_{\mathrm{hard}}(E,T) + I_{\mathrm{soft}}(E). \]

Soft-intensity regularization controls roughness and excessive amplitude, while retaining enough freedom to fit mixed materials, broad tails, and non-equilibrium gain/loss asymmetry.

Temperature scan

For each candidate temperature, nonnegative sparse source-intensity coefficients are optimized and the profile cost is recorded:

\[ C(T) = C_{\mathrm{data}}(T) + C_{\mathrm{src}}(T) + C_{\mathrm{ZLP}}(T) + C_{\mathrm{guard}}(T). \] \[ \hat T = \arg\min_T C_{\mathrm{smooth}}(T). \]

The scan uses a coarse-to-fine temperature grid followed by distance-aware smoothing. The reported cost valley comes directly from the stored raw and smoothed profile arrays.

BE linearity

Hard attention pairs satisfy

\[ \ln\left(\frac{p_i^+}{p_i^-}\right) = \frac{E_{M,i}}{k_BT}, \qquad i\in\mathcal H. \]

The fitted line is constrained through the origin. Soft source intensities and rejected pairs are shown only as diagnostic points and do not enter the temperature-linearity score.

9. Uncertainty And Reliability

The temperature uncertainty is estimated from the low-cost region around \(\hat T\). The default diagnostic interval contains candidate temperatures within ten percent of the local cost-valley rise.

Spectral goodness is summarized by

\[ R^2 = 1- \frac{\sum_E [y(E)-I_{\mathrm{fit}}(E)]^2} {\sum_E [y(E)-\bar y]^2}, \] \[ \mathrm{NRMSE} = \frac{ \sqrt{\left\langle[y-I_{\mathrm{fit}}]^2\right\rangle} } {\max(y)-\min(y)}. \]

Temperature reliability combines hard-pair coverage, BE linearity, uncertainty, anti-Stokes evidence, fit quality, boundary hits, and optimizer stability. A high full-spectrum \(R^2\) alone is not sufficient evidence for a reliable temperature.

Interpretation rule Reported temperature should be read together with hard-pair count, linearity, cost-valley width, reliability, and the gain-side residual.

10. Datacube Spatial Diagnostics

Datacube processing compares each fitted pixel with its local neighborhood using temperature, attention-peak position, signal-peak position, spectral profile, and fit quality:

\[ D_{\mathrm{nbr}}(x,y) = \operatorname{median}_{(u,v)\in\mathcal N(x,y)} \left[ \alpha_T |T_{xy}-T_{uv}| + \alpha_A \Delta A_{xy,uv} + \alpha_S \Delta S_{xy,uv} \right]. \]

Feature-aware weights reduce coupling across likely material interfaces:

\[ \omega_{\mathrm{edge}}(x,y;u,v) = \exp\left[ -\gamma\, \Delta_{\mathrm{feature}}(x,y;u,v) \right]. \]

Spatial repair targets isolated low-reliability pixels. Interface pixels are identified from spectral changes so genuine material boundaries are not flattened into neighboring temperatures.

11. Sparse Intensity And RL Analysis

Signed source-intensity representation

Fitted sparse phonon-mode source intensities can be mapped to a signed source-energy axis:

\[ P_{\mathrm{signed}}(-E_{M,i})=p_i^-, \qquad P_{\mathrm{signed}}(+E_{M,i})=p_i^+. \]

The signed source-intensity cube supports energy-window maps, NMF, clustering, and loss/gain mode comparison.

Richardson-Lucy diagnostic

When a fitted result is available, the fitted-ZLP kernel can be used as the point-spread function for deconvolving the reconstructed vibrational target:

\[ S_{\mathrm{target}}(E) = y(E)-I_{\mathrm{ZLP}}(E)-I_{\mathrm{bg}}(E). \]

RL output is a post-fit latent-signal diagnostic. Reconvolution with \(K_{\mathrm{ZLP}}\), residual quality, and stability across iteration counts should be checked before comparing peak positions.

12. Terminology And MATLAB Field Names

The coefficients \(p_i^+\) and \(p_i^-\) are described throughout this page as sparse phonon-mode source intensities. They are nonnegative source-space weights before convolution with the fitted ZLP kernel and are not, by themselves, an absolutely calibrated phonon DOS.

For compatibility with existing MATLAB result files, the code abbreviates phonon-mode intensity as PM. The main fields are PM_stokes, PM_antistokes, and EM_final.
