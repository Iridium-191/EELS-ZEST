# Release Audit

Build date: 2026-08-28

- Formal source is isolated in `version2.1_eels_zest`; the beta source remains
  unchanged.
- Eighteen cutoff/reconvolution, transferred-kernel RL, STA, EELS round-trip, robust multi-peak,
  hierarchy, interface, and temperature-map unit tests pass under MATLAB
  R2024b. SVG parameter-map export also passes.
- A GUI regression with deliberately mismatched pre-send and Stage 2 map sizes
  confirms a manual `100 meV` cutoff, visible spectrum/map refresh, exact
  reconstructed values, transferred 11x11 temperature context, and Stage 2 STA.
- The main GUI constructs and closes in hidden smoke mode without a parse or
  lifecycle failure. Scripted deletion leaves zero owned figures and zero
  timers.
- MATLAB `checkcode` covers 49 root/runtime/public example files with zero
  blocking parse diagnostics; 193 advisory messages remain.
- The bundled example 3x3 ROI Stage 2 smoke test passes with `R2=0.99999427`.
- The ZLP-stress 3x4 regression completes `12/12` fits; all 12 temperatures are
  Data-valid and every valid anchor is unchanged in the ZLP-guided map.
- The interface 4x8 regression completes `32/32` fits with two ZLP classes.
  Template-polish cancellation writes a checkpoint, Stage 2 reuse succeeds,
  and no automatic large plot is generated.
- Formal v2.1.0 and beta.4 small-system maps are numerically identical for R2,
  NRMSE, raw temperature, Data-valid temperature, ZLP-guided temperature, and
  reliability (maximum absolute difference `0`).
- `examples/data/example_data.mat` is the only bundled datacube.
- Internal numbered dataset labels and generated test outputs are absent from
  the archive.
- README, GUI guide, theory page, and project webpage use the v2.1.0 release
  terminology and point to the public GitHub repository.
- Release manifest hashes and the archive SHA-256 are generated by
