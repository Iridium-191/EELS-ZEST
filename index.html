EELS-ZEST

Zero-loss peak estimation, sparse phonon-mode source-intensity reconstruction, and attention-guided Bose-Einstein thermometry for spectra and datacubes.

1. Overview

Version 2.0 separates spectral reconstruction from temperature inference. The complete spectrum remains in the fit, while only reliable paired gain/loss evidence controls thermometry.

Stage 1

Fit the complete ZLP and reconstruct sparse vibrational signal.

Stage 2

Apply hard BE constraints to paired attention modes and independent soft source intensities elsewhere.

Diagnostics

Inspect residuals, sparse source intensities, BE linearity, cost valley, uncertainty, and maps.

On an aligned energy axis, the fitted total ZLP is used as the signal kernel and its center remains at 0 meV.

2. Installation

Add the toolbox folder to the MATLAB path:

addpath('EELS-ZEST');

Optimization Toolbox is required. Parallel Computing Toolbox is used when datacube parallel processing is enabled.

3. Quick Start

Launch the GUI

app = run_eels_zest;

Fit one spectrum

settings = struct();
settings.run_stage2 = true;
settings.crop_range = [-250, 250];
settings.stage2_temperature_algorithm = 'grid_scan';

result = eels_fit_spectrum(energy_meV, spectrum, settings);

Fit the bundled example

settings = struct();
settings.run_stage2 = true;
settings.crop_range = [-250, 250];
settings.datacube_sample_strategy = 'all';
settings.datacube_parallel_enabled = true;
settings.datacube_parallel_workers = 16;
settings.test_output_dir = fullfile(pwd, 'eels_zest_output');

input_file = fullfile('examples', 'data', 'example_data.mat');
cuberes = eels_fit_datacube(input_file, settings);

Run the prepared workflows

run(fullfile('examples', 'zest_datacube_full_stage1.m'));
run(fullfile('examples', 'zest_datacube_full_stage2_parallel.m'));

4. Workflow

  1. Load a `.mat` or `.dm3` spectrum image.
  2. Align the ZLP to 0 meV when needed.
  3. Apply rank-limited SVD/PCA denoising.
  4. Crop to the useful energy interval, normally [-250, 250] meV.
  5. Run Stage 1 and inspect ZLP, signal reconstruction, residual, R2, and NRMSE.
  6. Run Stage 2 where paired gain/loss evidence supports thermometry.
  7. Inspect hard-pair BE linearity, the temperature cost valley, uncertainty, and reliability.
  8. Export fitted spectra, sparse source-intensity products, maps, and diagnostics.

7. Outputs

Single-spectrum fields

  • raw_data, fitted_spectrum, residual
  • zlp_only, zlp_components, vib_only
  • sparse Stokes and anti-Stokes source-intensity arrays
  • metrics, stage2, T_fit, T_uncertainty, reliability_score

Datacube fields

  • R2_map, NRMSE_map, fit_status_map
  • T_map_raw, T_map_repaired, T_map_spatial_refined
  • T_uncertainty_map, reliability_score_map, attention_score_map
  • warning_map, bad_pixel_mask, interface_mask

11. Terminology And Field Names

The fitted coefficients are described here as sparse phonon-mode source intensities. They are nonnegative source-space weights before convolution with the fitted ZLP kernel, rather than a directly calibrated phonon DOS.

For compatibility with existing MATLAB result files, the code abbreviates phonon-mode intensity as PM. The corresponding fields are PM_stokes, PM_antistokes, and EM_final.
