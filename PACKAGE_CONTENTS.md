# Package contents

- MATLAB runtime, both GUI entry points and standalone reference tuner.
- Stage1/Stage2 solver, fitting/parallel/checkpoint helpers and native interfaces.
- C++ source in `native/`, build script and the Windows v22 MEX binary.
- `intmodes.mat`, `PK1.mat`, `logo.png`, EELS/DM3 support files.
- Small tests, English usage/release/native documentation, license and citation.
- `MANIFEST_SHA256.json` records each packaged file hash (excluding the manifest itself).

Excluded: experimental datacubes, user tuning reports, backups, generated output folders, machine-specific preferences and previous release archives. No executable installer or MATLAB Runtime application is included.
